For agentic workflows

      
Your agents open ports. You stay in command.

      
Six Claude Code sessions, each with its own dev server, test watcher and a database tunnel. Star Command shows what each one started, what it's holding on to, and when your Mac is starting to struggle.

      
    
        
  • Every session, with its descendants. Memory and CPU are summed over the whole process tree, not just the CLI.
    • 
        
  • The dev servers they spawned, and the ports each one is listening on.
    • 
        
  • Listeners on all interfaces are flagged, because an agent's 0.0.0.0 server is reachable from your network.
    • 
        
  • Stale and crowded sessions: sessions from days ago, several in one folder, and swap pressure, shown before your Mac starts to slow down.
    • 
        
  • Close what's lingering. Star Command checks that a closed session actually exited.
    •

Tunnels

    
Port forwards that stay forwarded. Toggle one, not the whole tunnel.

    
One switch per connection, one per forward. Star Command reconciles what you want with what's running, live, without dropping the forwards you didn't touch.


    

      

        

        
SSH, multiplexed

        
One ControlMaster per host. Forwards are added and cancelled with ssh -O, so a new port never costs a reconnect. Local, remote and SOCKS.

      

      

        

        
Kubernetes

        
Pick a context and namespace, then a service, deployment or pod from the list. A pod that dies restarts its own forward, nobody else's.

      

      

        

        
AWS without a bastion

        
SSM port forwarding to RDS, MSK and private hosts through a jump host found by Name tag, so autoscaled nodes are followed for you. MWAA gets a local sign-in gateway.

      

      

        

        
Self-healing

        
Dead links are caught within ~30 s and rebuilt with backoff. After wake or a network change every host gets a real round-trip probe.

      

      

        

        
SSO that renews itself

        
When a token expires, Star Command runs aws sso login for that profile and waits for you to approve it in the browser. You get one tab, however many tunnels share the profile.

      

      

        

        
Imports your config

        
Reads every LocalForward, RemoteForward and DynamicForward that ssh -G resolves, including Match and Include. Duplicate, copy and reorder forwards from there.

      

      

        

        
"Address already in use"

        
Star Command shows which of your processes is holding the port and offers Quit it, then retries. There's also a Free a port field for any port.

      

      

        

        
Process monitor

        
A sortable table of your processes with CPU, memory, disk, threads and listening ports. You can quit, force-quit, pause or renice them from there.

      

      

        

        
Stay awake

        
A caffeinate-style power assertion for 1, 4 or 8 hours, or for as long as any connection is on, so idle sleep doesn't take your tunnels down.

      

    

  







  

    
Resilience

    
Close the lid. Change networks. Come back to working ports.

    

      
t + 0s
Link dies
ServerAliveInterval, a dead forward process, or a failed probe after wake. Star Command notices.

      
t + 3s → 60s
Backoff
Reconnects at 3, 6, 12 seconds and so on, capped at a minute. A network change triggers an immediate retry.

      
if SSO expired
Re-auth
One browser sign-in per profile. If it isn't approved, Star Command waits 15 minutes before asking again, and Reconnect skips the wait.

      
connected
Forwards re-applied
Every enabled forward comes back. You get one notification for the drop and one for the recovery.

    

  






  

    

      
Install

      
Native, small, and yours to read.

      
Written in Swift and SwiftUI with no dependencies. Config is one JSON file in Application Support, and your keys stay in your SSH agent.

      

        
macOS14 Sonoma or later

        
SSHKey-based auth that works non-interactively (BatchMode=yes)

        
Kuberneteskubectl on your PATH or in Homebrew

        
AWSaws v2, plus session-manager-plugin for SSM forwards
